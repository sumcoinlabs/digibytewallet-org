What is DigiByte Wallet?


DigiByte Wallet is a 100% self custody, Mobile DGB Wallet that uses Electrum Protocol so there is very fast connection and zero sync time unlike SPV Protocol.



What DigiByte Wallet is not

DigiByte Wallet is not a company or exchange service, broker, advisor, middleman or trade facilitator. If you have not used DigiByte Wallet with Electrum based keys, you will need to generate a new wallet and words. Prior SPV wallet keys will not work.


• There aren't any hidden servers to backup or store your coins, you're in control 100%.


• Backup and recover your wallet on any device with the 'recovery phrase' generated by the app. Even if you lose your phone you will not lose your coins.


• As long as you store the 24 blockchain generated words in order (EXAMPLE: #1-#24) keep in a vault and NEVER share, you can have complete confidence in being your own bank.


• NEVER backup your recovery words using a camera/photo


• Send and receive coins at the touch of a button, anytime, anywhere and to anyone else using a wallet with the same coin.

Always Secure

Your coins are secured using Public Electrum Servers. DigiByte Wallet does not run these servers or have access to them. Electrum uses BIP39 security protocol.
BIP39 is a design implementation that defines how cryptocurrency wallets produce the set of words (or "mnemonic codes") that make up a mnemonic sentence, and how the wallet turns them into a binary "seed" that is used to create the encryption keys that are used to execute cryptocurrency transactions.
