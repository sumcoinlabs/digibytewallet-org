DigiByte Wallet 0.1.5: Original preview (November 5)

November 5, 2026  ·  DigiByte Wallet product update  ·  Preview, not a release notice

Update — November 12, 2026: Version 0.1.5 is now available through the App Store. This page preserves our original November 5 development preview. Read the release announcement for the current status.

A wallet update should make everyday use feel more dependable—not require users to understand how its software works. Version 0.1.5 is being prepared with practical refinements to security maintenance, iPhone startup, accessibility and on-screen advertising.

Status: DigiByte Wallet 0.1.5 is now available on the App Store. The original text below records what was known on November 5, before the app was released.

1. Keeping the software's security foundations current

Security starts with keeping the technologies an application relies on up to date. The 0.1.5 development work includes a coordinated refresh of Firebase-related dependencies and the Flutter/Dart development toolchain, including fixes related to certificate-validation vulnerabilities. An unused, discontinued Firebase Dynamic Links dependency is also being removed.

Why it matters to users: using supported, patched components helps reduce exposure to known issues. This is important maintenance, but we are not presenting it as a new independent security audit or claiming it makes any cryptocurrency immune to attacks.

2. A more dependable start on iPhone

The planned update improves how the app works with Apple's Keychain—the protected system storage used for sensitive app information—and how it starts after launching. These are behind-the-scenes adjustments, but they matter when you want your wallet to open predictably.

The upcoming release also raises the minimum supported iOS version to iOS 15. If you use an older Apple device, check its operating system compatibility before planning to upgrade.

3. Easier-to-read layouts

People do not all use the same screen size or text settings. Version 0.1.5 includes screen-scaling improvements intended to work better when larger system font sizes are enabled. The aim is to keep more of the important wallet information understandable and accessible.

The iPad interface is also being set to portrait orientation in the planned release. This is a product behavior change worth knowing about before updating.

4. Advertising that uses space more thoughtfully

Advertisements can help support ongoing development, but they should not get in the way of checking an address, reviewing a transaction or navigating the wallet. The 0.1.5 changes aim to reserve banner space only when an ad is actually available, rather than leaving unnecessary empty space on screen.

What this means: the interface should feel less cluttered when there is no ad to show. Actual ads and their placement may still depend on the device, region and advertising configuration.

5. Other refinements in development

Additional source notes mention enabling notification-open analytics on iOS and improvements to the automated build process. These are primarily maintenance and developer-facing updates. The goal is to make changes easier to verify and maintain over time.

DigiByte Wallet 0.1.5 is distinct from the newly published DigiCoinLib 0.0.3 development library. The library release was available earlier; the mobile wallet has since reached the App Store.

What stays central to DigiByte Wallet

Your wallet is designed around self-custody. Always keep your recovery phrase private and stored safely offline, and verify receiving addresses before sending funds.

Don't mistake a preview for a live update. Use the official store listing to check which version is actually available. Do not install third-party files claiming to be a preview or enter your recovery phrase in a web form.

Get DigiByte Wallet on your Apple devices

The current App Store listing supports iPhone and iPad. Apple also lists compatibility for Macs with Apple M1 chips or later, running macOS 11 or later. Mac availability can vary with your App Store region and device; the App Store determines whether your specific Mac can install it.

Version 0.1.5 requires iOS 15 or later on iPhone. The App Store link below currently opens the publicly available wallet, not an unreleased build.
